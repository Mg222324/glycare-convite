# glycare-convite

Página pública que o familiar abre pelo link do e-mail (aceitar/recusar e ver os dados permitidos).

Antes de publicar, edite `index.html` e troque, na constante `FUNCTION_URL`,
`SEU-PROJETO` pelo Reference ID do seu projeto Supabase.
Depois ative em Settings > Pages (branch main, pasta / root).
